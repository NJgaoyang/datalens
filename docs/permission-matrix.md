# 图表权限矩阵

## 实施状态

本文是权限合同。M01–M05 已实现认证、主题与图表授权；实现不代表生产部署或真实 StarRocks 验收通过。证据见各模块 acceptance 文档。

系统角色仅有 `SUPER_ADMIN` 和 `USER`。创建者和指定共享用户是资源关系，不是额外系统角色。账号由超管创建，不开放自行注册。

## 基础矩阵

以下“可以”均要求已登录、账号有效，并通过适用的数据策略检查。

| 操作 | 创建者 | 指定共享用户 | 其他普通用户 | 超管 |
| --- | --- | --- | --- | --- |
| 查看私有图表 | 可以 | 不可以 | 不可以 | 可以 |
| 查看指定共享图表 | 可以 | 可以 | 不可以 | 可以 |
| 查看全员共享图表 | 可以 | 可以 | 可以 | 可以 |
| 编辑、删除、改变共享范围 | 可以 | 不可以 | 不可以 | 可以 |
| 管理其他人的图表 | 不可以 | 不可以 | 不可以 | 可以 |

未登录或被禁用用户：全部拒绝。全员共享指系统内有效登录用户，不是匿名公开链接。导出为独立权限，查看、所有权或共享关系均不自动赋予导出许可；具体授予策略在 M09 明确并测试。

## 强制执行规则

1. 默认拒绝。统一权限服务负责图表、主题与查询授权，前端按钮隐藏不能代替服务端校验。
2. 请求主体来自服务端认证上下文，不采信客户端 userId 作为当前身份。
3. 查看共享图表只接收图表 ID 和允许的筛选参数。服务端加载已发布查询，不接受借共享权提交任意 SQL。
4. 共享发布须验证作者有权分享该结果范围。主题或数据策略被撤销时，关联图表停止查询或进入重新审核，发布快照不能永久绕过源策略。
5. 刷新创建任务、读取任务状态/结果、下载导出时重新验证当前权限，不能只检查任务 ID 或创建任务时的权限。
6. 列表、搜索、标题、缩略图、数量统计、缓存和静态资源遵守同一权限规则。列表查询不得泄漏无权资产的元信息。
7. 超管操作记录实际操作者、目标资源和变更；不得通过冒充作者实现管理。
8. Redis 缓存不作为授权的唯一真相。缓存失效与再次鉴权需覆盖撤权、禁用、所有权转移和策略变更。

## 必须覆盖的回归场景

- A 保存私有图表，B 无法列表搜索、读取详情、访问缩略图或猜 ID 读取结果。
- A 只共享给 B：B 可查看，C 不可查看；B 不可编辑、删除或修改共享。
- B 发起刷新后 A 撤权：B 即使拥有原任务 ID，仍不可读取随后完成的结果。
- 指定共享改为私有后旧会话、缓存和下载地址不能继续提供内容。
- 全员共享只允许有效登录账号；账号禁用后旧会话立即按策略失效。
- 超管可管理其他用户图表，审计仍记录超管真实身份。
- 回收站恢复、所有权转移必须重新校验操作权限和共享关系。
- 导出创建和下载分别鉴权，文件过期或撤权后拒绝旧地址访问。
- 数据源/主题权限撤销后，图表已发布版本不能继续越权执行。

## M05 安全实现细节

- 主题分享策略 NONE 禁止共享；AUTHORIZED_USERS 仅允许主题已授权用户的指定共享；ALL_AUTHENTICATED 允许分享结果给任意有效登录用户或全员。三种策略均不授予额外自由查询能力。
- 共享者仅看到口径、图表规格、时间规则和结果。SQL、主题 ID、绑定参数、共享名单只对所有者和超管提供。
- 所有者当前账号、主题、字段、数据源版本和结果分享策略在执行及结果读取时再次校验。超管查看不绕过作者的数据策略。撤权仍可在源停用或作者禁用后操作。
- 新内容发布、删除、恢复、所有权转移都恢复私有；恢复和转移生成新的不可变安全修订，旧任务不能复活。
- 查询任务实际操作者始终是查看者；作者仅作为数据策略检查对象，不创建冒充作者的会话或审计。
- 回收站无公开查看路径，所有者可恢复自己的图表，超管可恢复任意图表。转移仅超管可执行，目标需有效账号且有查询该定义的权限。
- 导出尚未开放，任何查看或共享不自动获得导出权限。
