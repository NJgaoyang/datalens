# DataLens 全新项目基线（自 2026-11-04 起）

## 开发约束：只设计新系统

`dev20261104` 是独立项目的当前开发分支，**不兼容此前分支的代码、路由、接口、表结构或配置**。以本分支的产品体验与可维护代码为准；旧模块若无价值可以重写或删除，不做历史接口适配、不添加旧字段兼容逻辑，也不为旧版本设计升级脚本。已废弃的 M00–M10 文档仅供理解开发历史，不能阻碍当前重设计。

**不兼容不等于可随意清库**：开发默认在新建空的 MySQL 8 数据库中初始化。若目标库已经包含历史数据，服务不会主动 DROP/CLEAN；应另行配置空库或取得明确授权、完成备份后由用户手工处置。重启已初始化的当前项目不应重置管理员密码、覆盖账号或重复导入初始数据。

## 当前技术和部署

- Java 21 / Spring Boot 模块化单体，Vue 3 / TypeScript / ECharts；业务接口只供当前前端使用。
- MySQL 8 存储系统元数据、账号、权限、会话、查询任务、对话与图表；Spring Session JDBC，不需要 Redis。
- StarRocks 是可选的外接只读分析数据源，与系统 MySQL 隔离。模型配置也可选，应用在未配置时仍能启动。
- 使用 `bash package.sh` 打包为 `tar.gz`；解压后编辑 `conf/application.env`，用 `bin/start.sh`、`bin/stop.sh` 管理；直接 IP+端口访问，不使用 Docker、Nginx。

## 初次安装默认值

| 配置项 | 默认值 | 限制 |
| --- | --- | --- |
| MySQL 主机/端口 | `127.0.0.1:3306` | 本机新空库 |
| MySQL 用户名 | `root` | 仅用于初次安装，正式环境应改用专用账号 |
| MySQL 密码 | `123456` | 公开示例默认密码，不是生产密码 |
| 系统初始管理员 | `admin` | 仅在没有任何用户时创建 |
| 初始管理员密码 | `admin@123456` | 首次登录后必须修改 |
| Web 地址 | `http://服务器IP:8088` | 裸 HTTP 只用于可信环境；公网需 TLS 与防火墙 |

这些是用户明确选择的“首次安装默认值”，不是私密凭据。默认值可在 `conf/application.env` 用环境变量覆盖。服务器启动时仅提醒正在使用默认值，不应将密码正文写入日志。首次管理员创建后，清空 `DATALENS_BOOTSTRAP_USERNAME`、`DATALENS_BOOTSTRAP_PASSWORD` 并重启；重复启动不修改现有密码。严禁用这些默认值暴露到互联网。

## 新版本验收

每次改动以当前项目首次安装与功能闭环为准：空 MySQL 初始化；同版本重复启动；认证/会话/权限隔离；只读查询、安全校验；问数/图表保存和共享；前后端构建与 CI；原生 tar 包测试。**不为旧分支进行 schema、API、界面升级回归**。有风险的数据销毁操作必须单独得到明确授权，并核实目标实例。
