# D02 · C 端智能问数界面交付

用户在本轮对话中选定的第二版 DataLens 智能问数设计图是视觉基准。直接在 **dev20261104** 分支改造现有 Java/Vue 项目，不使用静态截图作为页面。

## 本轮实施

- 页面主布局：左侧 264px 入口导航（新建问数、智能问数、我的图表、图表中心、管理员数据源、分析空间与最近会话），右上账户、问数帮助和搜索；搜索会话从授权列表过滤，图表检索交由后端过滤。
- 首次空库：显示欢迎引导、具体操作路径、示例问法、禁用不允许的提交按钮；管理员可直接进入数据源、主题和语义配置。零授权数据不插入虚构示例结果。
- 有数据的问数：用户问题、服务端回答状态、已审核指标/时间/维度理解卡；结果卡提供授权数据的 ECharts 图/表/说明，展示原始高精度，支持每页 10 行。
- 数据洞察：只依赖当前结果；单指标、完整结果、精确十进制列可比较最高值，不计算不完整结果的占比或总额；若无足够证据仅提供返回行列数。
- 保存图表：必须主动打开弹窗并确认，默认私有；共享/导出通过已有图表详情权限接口，未保存不可共享。
- 右侧区域：仅列出 GET /subjects 与按当前主题授权获取的 metadata，不展示未授权表/字段或假业务数据；移动端右侧栏隐藏时提供独立分析空间选择器。
- 安全：权限拒绝清空会话数据及应用级历史标题，账号登出与切换释放已有数据；请求持有 actor/route/abort 令牌，旧响应不能在新页面显示。

## API / 数据库 / 非目标

复用现有会话、主题/元数据、图表 API，不更改后端业务接口或迁移；数据库、打包和运行方式不变。**不冒充已实现通用自然语言生成自由 SQL**，目前仅使用已发布的审核业务口径；追问条件不支持时仍交由后端澄清。没有伪造 SQL、销售明细、趋势数或图表数据。

## 自动化验收

CI 使用 Node 22 + `npm ci && npm run test && npm run build && npm run test:e2e`；后端使用 Java 21 + 临时 MySQL 运行 `mvn -f server/pom.xml verify -Pintegration`。浏览器增加 screenshot 夹具：`d02-empty-desktop.png`、`d02-result-approved-1648.png`、`d02-mobile-390.png`，并验证空库无 POST、用户数据真实表名、结果图表、无浮点伪汇总、键盘/保存权限和窄屏选择器。模拟请求只证明 UI/权限表现，不代表真实 StarRocks/模型正确性。

当前仓库不兼容旧项目版本或库表，但不会自动清理已有数据库。本轮未部署，不修改生产数据。
